# ARO workload landing zone

This private repository is generated by ALZ.ARO. Terraform owns a new private ARO cluster, its resource group, VNet, and control-plane/worker subnets. In `spoke` mode it also owns bidirectional peerings and a default route to an existing firewall/NVA; it does not own those platform resources.

## Delivery

Pull requests run formatting, validation, Checkov, and a speculative plan. Deployment is never automatic: manually dispatch the protected apply workflow with a full commit SHA. It creates a plan from that SHA, uploads it, waits for the `apply` environment approval, and applies the exact artifact. Destroy is manual-only and requires the default branch, its exact SHA, the word `DELETE`, and approval.

Configure these secrets in both `plan` and `apply` environments before planning: `ARO_SERVICE_PRINCIPAL_CLIENT_ID`, `ARO_SERVICE_PRINCIPAL_CLIENT_SECRET`, `ARO_SERVICE_PRINCIPAL_OBJECT_ID`, `ARO_RESOURCE_PROVIDER_OBJECT_ID`, and optionally `REDHAT_PULL_SECRET`. Azure pipeline authentication itself is secretless GitHub OIDC.

`front_door` records follow-on integration intent only. `application_gateway` is preview, disabled by default, and does not provision a gateway in this release.

Dependabot proposes monthly Terraform and GitHub Actions updates. Actions use stable major tags in the initial scaffold; pin organization-reviewed commit SHAs if required by policy.
