# ARO workload landing zone

This private repository is generated by ALZ.ARO. Terraform owns a new private ARO cluster, its resource group, VNet, and control-plane/worker subnets. In `spoke` mode it also owns bidirectional peerings and a default route to an existing firewall/NVA; it does not own those platform resources.

## Delivery

Pull requests run formatting, validation, Checkov, and a speculative plan. Deployment is never automatic: manually dispatch **02 ARO Landing Zone Continuous Delivery** from the default branch and select `apply` or `destroy`. It verifies the selected default-branch commit, creates and uploads the corresponding plan, waits for the `apply` environment gate when supported, and applies the exact artifact.

Configure `REDHAT_PULL_SECRET` in both `plan` and `apply` environments when required. For Application Gateway TLS, also configure `APPLICATION_GATEWAY_SSL_CERTIFICATE_DATA` and `APPLICATION_GATEWAY_SSL_CERTIFICATE_PASSWORD`. Azure pipeline and ARO authentication use managed identities without client secrets.

`front_door` records follow-on integration intent only. `application_gateway` is preview, disabled by default, and does not provision a gateway in this release.

Dependabot proposes monthly Terraform and GitHub Actions updates. Actions use stable major tags in the initial scaffold; pin organization-reviewed commit SHAs if required by policy.
